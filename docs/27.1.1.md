# MacFlow 27.1.1
Reparación acotada sobre una copia de 27.1.0, conservada intacta. La grabación recibida dura 7 segundos y sólo muestra el Dock; no permite verificar visualmente la isla.

Causas de código verificadas: CanToggle se interpretaba como reproducción activa; ausencia de actividad ocultaba la cápsula; una excepción de lectura descartaba el estado anterior. El modo iPad dejaba de cubrir su monitor al ocultar Inicio. Windows elegía sólo su sesión multimedia actual, aunque otro reproductor estuviera sonando.

Se conserva la cápsula neutra, sin onda/carátula en pausa. Se prioriza la sesión de Windows que realmente está reproduciendo y se escuchan cambios de las otras sesiones. Se mantiene el modo iPad al entrar a una app y se repone la prioridad del borde propio. Al entrar el cursor, se mantiene únicamente el reemplazo de barra ya autorizado en las preferencias; nunca se habilita por defecto.

Sin inyección, cambios de estilo ajenos, inicio automático, publicación ni instaladores ejecutados. La ocultación real de la barra de Windows y Roblox en pantalla completa requieren prueba física autorizada; no se declaran solucionados sin esa prueba. Los navegadores deben publicar sus sesiones multimedia a Windows: no se captura audio ni se leen pestañas privadas para simular esta compatibilidad.

Verificación ejecutada: compilación offline completa, 257 comprobaciones automáticas y 54 verificaciones visuales aprobadas. Se verificó SHA-256 del instalador. Las nuevas regresiones cubren pausa con controles todavía disponibles, cierre del reproductor, error transitorio de lectura y lanzamiento de una app en modo iPad sin reaparecer el Dock Mac. Se corrigió una fixture que perdía su carátula al probar el cierre; no fue un fallo de producción.

La consulta multimedia real (--media-smoke) devolvió UnauthorizedAccessException/Acceso denegado en este entorno. Por ello la selección de sesiones del navegador está implementada, pero su funcionamiento con Chrome real no está validado. No se oculta este resultado. Tampoco se probó la barra real de Windows ni Roblox: requieren verificación física. No se ejecutó el instalador, no se publicó y no se habilitó inicio automático. Para revertir, se conserva completa la carpeta MacFlow-27.1.0.
