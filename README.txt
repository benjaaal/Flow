ACTUALIZACIÓN EN DOS ETAPAS
26.5.0 BASE LIVIANA: compatible con el límite de 64 MB de 26.4.1. Incluye mejoras visuales, estabilidad, Dock, isla, Centro de control, widgets y Privacidad con PIN. Conserva preferencias. No incluye todavía voz ni motor facial.
26.5.1 COMPLETA: desde Configuración → Sistema → Actualizaciones en la base. Incluye los modelos locales de voz español/inglés y reconocimiento facial experimental. El actualizador de la base admite hasta 256 MB.
La publicación 26.5.0 permanece como entrada del canal para versiones antiguas. La base consulta 26.5.1 y la completa vuelve al canal estable para futuras actualizaciones. Los canales personalizados se conservan.

USO
Hey Siri: activalo en Sistema después de instalar 26.5.1. Dictado español local. Windows debe permitir el micrófono a aplicaciones de escritorio. Preguntas libres mediante Gemini en Chrome: requiere sesión y accesibilidad.
Ctrl+Windows abre Privacidad; música y tareas continúan. PIN propio de 6–12 números. Cinco intentos fallidos activan una espera de 30 s.
Ctrl+Windows+Alt recupera el escritorio. No reemplaza el bloqueo seguro de Windows.
Rostro experimental disponible en 26.5.1: creá un PIN, registrá el rostro y luego elegí Reconocer rostro. Sin Windows Hello. YuNet/SFace comparan identidad; MiniFASNet comprueba presencia y pide un giro. Una webcam RGB no garantiza rechazar todos los engaños ni equivale a Face ID. No guarda fotos ni audio; perfil protegido con DPAPI. Cámara y micrófono físicos y ataques reales requieren validación en cada equipo.
Pliegue: prueba manual y alternativa 3D; el movimiento físico depende de sensores/avisos de tapa. La suspensión puede interrumpirlo.
Las animaciones de ventanas externas se limitan a aplicaciones compatibles; no sustituye el compositor ni anima diálogos protegidos.
Salir desde la bandeja restaura la barra de Windows; MacFlow.exe --restore también permite restaurarla. Privacidad mantiene despierto el equipo mientras está abierta, respetando apagado manual, tapa, bloqueo de Windows y batería crítica.
