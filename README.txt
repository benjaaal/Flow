MacFlow 28 Final Edition — Windows 11 x64

Hacé clic en la manzanita para abrir el menú principal. Launchpad y Spotlight
incluyen las aplicaciones integradas. En Finder podés cambiar entre lista,
iconos, galería y columnas. Agregá las carpetas que Spotlight puede indexar en
Configuración → Preferencias.

Los escritorios virtuales se gestionan con Vista de tareas de Windows desde
Mission Control. Para bloquear de forma segura la sesión, usá Windows+L.

Configuración → Privacidad permite elegir órdenes locales, un modelo de Ollama
instalado en este equipo o Gemini en tu sesión de Chrome.

Para volver al escritorio de Windows, elegí Salir de MacFlow en el menú.
Ejecutá el instalador de nuevo para actualizar o reparar los archivos de la app.
